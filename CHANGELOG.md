# Changelog

## 0.1.0

First release.

* Highlighting for `.storm` files and ```` ```storm ```` blocks in Markdown.
* Lint as you type: Storm syntax errors, Synapse's `StormLinter` rules, and checks against the data model,
  commands, command arguments, `$lib` and variables.
* Completion for forms, props, commands, `$lib` and tags, and docs on hover.
* A temporary in-process Cortex by default, or a real Cortex over telepath.
